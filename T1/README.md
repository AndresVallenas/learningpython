# T1: Calculadora de promedios

Programa de consola desarrollado con Python para registrar materias y calificaciones, calcular el promedio e identificar asignaturas aprobadas, reprobadas y calificaciones extremas.

## Conceptos utilizados

- Programación estructurada y separación en funciones.
- Listas y correspondencia mediante índices.
- Bucles `while` y `for`.
- Condicionales y parámetros con valores predeterminados.
- Validación de entradas con `try-except`.
- Conversión de datos con `float`.
- Funciones integradas como `sum`, `len`, `min` y `max`.
- Anotaciones de tipos.
- Punto de entrada `if __name__ == "__main__":`.

## Funcionalidades

- Registro de materias y calificaciones entre 0 y 10.
- Umbral de aprobación configurable, con valor predeterminado de 5.0.
- Cálculo del promedio general.
- Clasificación de materias aprobadas y reprobadas.
- Identificación de la mejor y la peor calificación.
- Gestión del caso en que no se registren materias.

## Ejecución

```bash
python3 calculadora_promedio.py
```
